# 🏥 Doctor Booking Management System

## 📖 Overview

The **Doctor Booking Management System** is a web-based application that helps patients easily book appointments with doctors. It simplifies the traditional appointment process by allowing users to register, search for doctors, and schedule appointments online.

The system also provides separate dashboards for **Admin**, **Doctor**, and **Patient**, ensuring efficient management of healthcare services.

---

## 🚀 Features

### 👤 Patient Module

* User registration and login
* Search doctors by specialization
* Book appointments online
* View and manage appointment history
* Cancel appointments

### 👨‍⚕️ Doctor Module

* View scheduled appointments
* Manage availability
* Update appointment status

### 🛠️ Admin Module

* Add, update, and delete doctor records
* Manage patients
* View all appointments
* Maintain system data

## ⚙️ Installation & Setup

1. Clone the repository:

   ```
   git clone https://github.com/rohanjadhav5054/Doctor-Booking-Management-
   ```

2. Move the project folder to:

   ```
   C:\xampp\htdocs\
   ```

3. Start XAMPP:

   * Start Apache
   * Start MySQL

4. Import the database:

   * Open phpMyAdmin
   * Create a database (e.g., `doctor_booking`)
   * Import the `.sql` file from the project

5. Run the project:

   ```
   http://localhost/Doctor-Booking-Management-
   ```
